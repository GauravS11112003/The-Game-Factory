# Draw-a-Level

Draw a platformer on a printed sheet (or on screen), scan it with a phone, and
play it ten seconds later with your own doodle as the character. Black ink is
ground, red is spikes and enemies, green is the goal, blue is coins and keys.
Handwritten rules become mechanics: "this platform moves" with an arrow makes
it move, "door opens with the key" wires a key to a door. Print any level in
light gray, draw on top of it and scan it again to publish a remix that credits
the original. Everything compiles to one level JSON (`shared/level.schema.json`),
so the engine, the editors and the remix tree all speak the same format.
Background and pitch: [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md). The locked
build plan: [PLAN.md](PLAN.md).

## Run

```bash
# one-time setup
cd vision && uv venv --python 3.11 && uv sync && cd ..
cd web && npm install && cd ..

# both servers (API on :8000, web on :5173, prints the LAN URL for phones)
scripts/dev.sh

# or separately
cd vision && uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
cd web && npm run dev

# checks
cd vision && uv run pytest -q
cd web && npx tsc --noEmit && npm run build && npm test

# printable blank sheet -> ./out/blank.pdf
scripts/print_templates.sh

# photo -> level JSON on the command line
cd vision && uv run python cli.py photo.jpg --out level.json --debug ./dbg

# regenerate the fixture levels / the synthetic test photos
python3 shared/fixtures/make_levels.py
cd vision && uv run python tests/make_synthetic.py --count 3 --seed 1 --force
```

## Games, levels and remixes

The platform is a feed of **games**; a game is an ordered sequence of
**levels**. The first boot seeds "Starter World" (three levels: First Steps,
Spike Valley, Key Cave) plus a remix chain under First Steps so the tree page
has something to show. From the home page or a game page:

- **Add a level** to a game: draw on screen or scan a sheet with `?game=<id>`
  (or print the add-a-level sheet, whose QR carries the game id); publishing
  appends it to the game's sequence.
- **New game**: draw or scan with no game selected; publishing creates a game
  named after the level.
- **Remix** a level: print its remix sheet (gray overlay + QR) or "Remix on
  screen"; the child joins the parent's game but hangs under the parent in the
  remix tree instead of extending the sequence (it keeps the parent's
  `order_index`, so "Next level" after a remix continues the game).

The vision model runs in fake mode whenever `ANTHROPIC_API_KEY` is unset:
typed rules (canvas path) and the fixtures in `shared/fixtures/interpretations/`
are read by the heuristic in `vision/app/llm/heuristic.py`, so "the platform
moves right 8 cells, timer 60" works offline.

Environment (all optional): `ANTHROPIC_API_KEY` (unset = the vision model runs
in fake mode from `shared/fixtures/interpretations/`), `DAL_FAKE_LLM=1`,
`DAL_DATA_DIR` (default `vision/data`, holds `dal.sqlite` and `uploads/`),
`DAL_PORT` (8000), `DAL_PUBLIC_UPLOADS` (`/uploads`). The web app only talks to
the Vite port; `/api` and `/uploads` are proxied to the API. Health check:
`curl localhost:8000/api/health` -> `{"ok": true, "llm": "fake"}`.

## Folder map

```
shared/                 contracts every lane builds against
  level.schema.json     JSON Schema (draft 2020-12) for a level, single source of truth
  behaviors.md          the fixed behavior vocabulary and the compile validation rules
  template_spec.json    every printed-template coordinate in mm; generator and CV read it
  fixtures/levels/      3 Starter World levels (generated by fixtures/make_levels.py)
  fixtures/interpretations/   fake vision-model outputs, looked up by sha1 of the image
  fixtures/photos/      synthetic photos from vision/tests/make_synthetic.py
vision/                 Python 3.11, FastAPI, OpenCV, Pillow, SQLModel, anthropic (uv)
  app/main.py           FastAPI app, CORS, /uploads static mount, routers, /api/health
  app/config.py         settings from env; fake LLM mode when the key is missing
  app/models.py         Pydantic contracts: Level, CVResult, Binding, Interpretation
  app/template/         sheet generator (blank, add-a-level, remix) and spec loader
  app/cv/               rectify, calibrate, segment, components, sprite, pipeline.run_scan
  app/llm/              prompt builder and interpret() with fake mode and fallbacks
  app/compile.py        CVResult + Interpretation (+ parent) -> Level
  app/routers/          scan, levels, games, templates
  app/db.py, seed.py    SQLite via SQLModel; Starter World seed
  cli.py                photo -> level JSON
  tests/                schema, rectify, segment, pipeline, compile, interpret, api (uv run pytest -q)
web/                    Vite + TypeScript + Phaser 3, no UI framework
  src/main.ts           hash router -> screens
  src/api.ts            typed fetch wrappers, apiBase
  src/types.ts          TS mirror of the level schema
  src/screens/          home, scan, canvas, play, tree, remix
  src/game/             constants, mountGame, LevelScene, Player, behaviors, rules, hud, touch
  src/solver/           solve() reachability check run before publish
  public/assets/        default_player.png (the fallback doodle)
scripts/
  dev.sh                starts both servers, prints the LAN URL
  print_templates.sh    writes out/blank.pdf
docs/checklist.md       manual demo checklist
```
