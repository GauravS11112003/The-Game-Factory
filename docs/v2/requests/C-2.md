# C-2: message keys for scan warnings (lane F, `shared/spec/messages.json`)

Lane C · See. Status: open.

`run_scan_v2` returns warnings as `MessageRef`s, in `ScanV2.warnings` and in each `SheetInfo.warnings`.

**Keys already in `messages.json` that lane C uses:**
- `warning.sheet_missing {n, k}`
- `warning.duplicate_sheet {n}`
- `warning.specks_ignored {n}`
- `error.paper_missing`, `error.no_drawing`, `error.upload_failed`, `error.bad_request` (`ScanV2Error.message`)

**Please add these keys.** The suggested sentences are kid-facing and ≤ 12 words.

| Key | Args | Suggested sentence |
|---|---|---|
| `warning.qr_not_read` | n | "I couldn't read sheet {n}'s code. I guessed its place." |
| `warning.marker_inferred` | n | "One corner of sheet {n} was hidden. I worked around it." |
| `warning.calibration_fallback` | n | "The colour squares on sheet {n} were hard to see." |
| `warning.pencil_marks` | n, count | "I saw {count} light pencil marks. Trace them with a marker." |
| `warning.thin_ink` | n | "Thin lines are hard to see. Thick markers work best." |
| `warning.photo_unreadable` | i, why | "I couldn't read photo {i}. Show the whole sheet." |
| `warning.not_a_drawing_sheet` | i | "Photo {i} is a rules or library sheet, not a level." |
| `warning.other_pack` | n | "Sheet {n} is from a different pack." |
| `warning.sheet_out_of_pack` | n, k | "This pack has {k} sheets, so I skipped sheet {n}." |
