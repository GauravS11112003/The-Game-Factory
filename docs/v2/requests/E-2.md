# E-2: engine and render additions for ghosts, themes, music, share cards and the results moment

From lane E (Feel), wave 2. Everything below is additive and optional: existing calls keep working unchanged.
Affects lane F (app, editor, messages.json) and lane D (sprite and sheet URLs).

## 1. Engine API additions (`web/src/engine/types.ts`, `web/src/engine/index.ts`)

`MountOptions`:
- `rules.theme` / `rules.music` now **win over the level's snapshot** (both are cosmetic and outside `level_hash`). Pass the
  game's rules (or the theme picker's choice) to preview a draft in its game's theme. Passing `level.rules` behaves as before.
- `music?: boolean`: the level's music loop on or off (default: `rules.music`, else on). The player's own ♪ setting
  (persisted as `dal.v2.music`, toggled by the new HUD ♪ button) still applies on top.
- `underlay?: boolean`: "my original sketch" at 15% behind the level (§7.2), from `level.source.sheets[].sketch_url`
  (else `photo_url`); sheet *n* is stretched over cells 48·(n−1) … 48·n.
- `ghosts[]` gained `sprite_url?` (the runner's character PNG from `GET /runs/{id}`, pencilized), `kind?`
  (`'pb' | 'you' | 'leader' | 'challenger' | 'bot' | 'other'`, inferred as `bot` from the label otherwise) and
  `sync?` (`'race'` default in play/test: the ghost starts with your first input, so it races your clock; `'free'`
  default in preview: runs at 1× from the mount, loops, and the camera follows it until the kid presses a key).

`GameHandle`:
- `setTheme(theme)`, `setRules(partialRules)` (theme + music only), `setMusic(on)`: swap in place, the run continues.
- `setUnderlay(on): boolean` (false when the level has no sheet photos).
- `snapshot({ hud?: false }): Promise<Blob | null>`: the current frame as a PNG (the win moment for a share card).
- `ghosts(): GhostResult[]`: live ghost status.

`'win'` payload (`WinPayload`) gained `ghosts: [{label, kind, finished, time_ms, deaths, beat}]`: the race ghosts when
the win was emitted; `beat` is true when you finished first (a ghost still running counts as beaten). The results card
can say "You beat Maya by 1.32 s!" before the server verifies the run.

`'ready'` payload gained `theme` and `underlay` (whether the level has sheet photos).

## 2. Asks for lane F

1. **Ghost sprites and kinds** (`screens/play.ts`): pass `kind: 'challenger'` and `sprite_url` (from `api.run(vsId)`)
   for the `?vs=` ghost, and `kind: 'pb'` for "Watch ghost". The PB ghost needs no sprite (it falls back to the level's
   character, drawn as a pencil copy).
2. **Results sounds** (`results.ts`): the mixer now has `'whoosh'` (card slides in), `'stamp'` (the rubber-stamp thunk;
   use it instead of `'land'`), `'tick'` (tallying numbers), `'pb'` (new best) and `'beat'` (beat a rival's ghost).
   Please don't call `mixer.setMuted(store.flag('muted'))`: it **writes** the engine's persisted mute. Use
   `createMixer({ muted: store.flag('muted') })`, which sets it for that mixer only.
3. **Share cards** (`render/sharecard.ts`, re-exported from `engine/index.ts`):
   - at publish: `shareCardPNG(level, ink, { title, author })` gives the 640 × 360 card with the taped title plate,
     band and ink drops; `{ style: 'clean' }` gives the bare picture if the feed thumbnail must stay text-free;
   - "Challenge a friend": `shareCardFile(level, ink, { run: { player, time_ms, deaths, coins, big_coins, stamps } })`
     for `navigator.share({ files: [file], url })` (feature-test `navigator.canShare({ files })`). Optionally pass
     `picture: await createImageBitmap(await handle.snapshot({ hud: false }))` to use the real win frame.
4. **Theme picker** (`#/game/:id/rules`, P5): `themeCatalog()` (names, paper, ink, loop scale), `themeSwatch(theme,
   cssWidth, { character, selected })` (a live sample level through the real renderer), `auditionTheme(theme)` (two
   bars of the theme's loop; call from a click) and `handle.setRules({ theme, music })` for the mini-stage.
5. **Character Studio** (`editor/studio.ts`): `new RigPreview(strokes).draw(canvas, dtMs)` runs the mini-stage with the
   exact rig animation the game uses (`core/art/anim.ts` RigAnimator: run, skid, jump squash, apex, land stretch, idle
   breathing and bob, blinks, the jelly sway). `setStrokes()` as the kid draws.
6. **messages.json keys** used by lane E canvases (English fallbacks are built in until they exist):
   - `theme.sketchbook` "Sketchbook", `theme.notebook` "Notebook", `theme.graph` "Graph paper", `theme.kraft` "Brown paper";
   - `share.beat_my_time` "Beat my time!", `share.play_it` "Can you clear it?";
   - `share.screens` "{n} screens", `share.screen_one` "1 screen".
   Existing keys reused: `band.*`, `stamp.*`, `play.by`, `ui.untitled`.

## 3. Asks for lane D

- `GET /api/v2/runs/{id}` → `sprite_url`: a PNG of the runner's character, transparent or on plain light paper, served
  same-origin (or with CORS) so the engine can read its pixels. The engine trims it, keys out a plain background,
  finds the feet and draws it as a pencil copy.
- `level.source.sheets[].sketch_url`: the rectified drawing area of sheet *n* (48 × 27 cells). The underlay stretches
  it over that screen.
