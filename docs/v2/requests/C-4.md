# C-4: message keys for stitching, the rules sheet and the library sheet (lane F, `shared/spec/messages.json`)

Lane C · See. Status: open.

Lane C emits these keys as `MessageRef`s:
- in `ScanV2.warnings`;
- in `ScanV2Error.message`;
- in `RulesSheetResult.asks` and `x_warnings`;
- in `LibraryDraft.asks` and `warnings`.

None of them is in `messages.json` yet. The suggested sentences are kid-facing and ≤ 12 words.

**Arguments.**
- `{row}` and `{option}` on the rules sheet carry the **printed English label** (for example "Double jump", "3 lives"),
  so they can be shown as they are.
- On the library sheet, `{a}`, `{b}` and `{option}` are the checkbox ids: walks, hops, flies, shoots, chases,
  crushes, spiky, slow, fast.

## Paper levels (stitching)

| Key | Args | Suggested sentence |
|---|---|---|
| `warning.parent_unavailable` | - | "I couldn't find the level you remixed, so I used just your drawing." |
| `warning.parent_ink_skipped` | n | "{n} lines from the old level were broken, so I left them out." |
| `error.level_too_long` | max | "This level already has {max} screens, the most a level can have." |

## Rules Sheet

| Key | Args | Suggested sentence |
|---|---|---|
| `error.wrong_sheet` | expected, got | "That's a different kind of sheet. Show the right one." |
| `error.not_rules_sheet` | - | "I couldn't find the rule boxes. Show the whole rules sheet." |
| `warning.rules_code_unread` | - | "I couldn't read this sheet's code. Is it for this game?" |
| `warning.rules_nothing_ticked` | - | "I didn't see any ticks, so nothing changed." |
| `ask.rules_two_ticks` | row, a, b, n | "{row}: you ticked {a} and {b}. Which one?" |
| `ask.rules_unsure` | row, option | "{row}: did you mean to tick {option}?" |

## Library Sheet

| Key | Args | Suggested sentence |
|---|---|---|
| `error.not_library_sheet` | - | "I couldn't find the creature boxes. Show the whole sheet." |
| `warning.library_code_unread` | - | "I couldn't read this sheet's code. Is it for this game?" |
| `ask.library_two_moves` | box, a, b | "Creature {box} {a} and {b}? Pick one way it moves." |
| `ask.library_slow_and_fast` | box | "Creature {box} is slow and fast? Pick one." |
| `ask.library_unsure` | box, option | "Creature {box}: did you tick {option}?" |
| `warning.library_no_drawing` | box | "Creature {box} has ticks but no drawing yet." |
| `warning.library_symbol_incomplete` | box, count | "Draw creature {box}'s symbol 3 times (I saw {count})." |
| `warning.library_speed_without_move` | box | "Creature {box} stays still, so slow or fast does nothing." |
