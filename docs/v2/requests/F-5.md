# F-5: what the P5 screens use from the core (lanes B, A, E)

Lane F · Studio. Status: informational, plus two small asks. Everything runs in the browser core worker
(`web/src/app/core_tasks.ts`) or on the main thread where noted; a `NotImplemented` becomes a kid sentence.

## Lane B
- **Prompt drafts:** `keywordPlan(prompt, screens)` → `generateLevel(plan, rules, seed, {tier: 'faithful', clamp:
  'band', ink: 'draft'})` with `seed = FNV-1a(prompt)`; `layoutPlan` + a Faithful build is the fallback. The editor
  treats strokes with `origin: "draft"` as draft objects:
  - "your ground wins": a new kid stroke or stamp whose box overlaps a draft object's box with IoU ≥ 0.3
    (`PROMPT_LEVEL.draft_replace_iou`, both boxes padded to ≥ 1 cell) removes that object's draft strokes in the same
    undo step; objects come from the hints' scene objects;
  - "Ink it" recolours draft strokes with the same role → marker table as `generate.ts` `inkIt` and sets
    `origin: "kid"`.
- **Rules dry run:** `rulesCheck(levels, rules, {repair})` — the same helper as the server's route.
- **Remix diff:** `remixDiff(parent, ink)`; `added` component ids are mapped to strokes on
  `ensureComponents(withParentInk(ink, parent))`. The editor passes the published parent to `perceiveHeuristic` /
  `build` for remixes.
- **Library instances:** "Save to library" on a level object re-tags its strokes with `stamp: "library"`,
  `lib: {type_id, version}` and `rule: <type behavior>`.
- **Ask:** export `generateLevel` / `withParentInk` keep their current signatures (the app imports them).

## Lane A
- Rules mini-stage: `jumpArcs(profile, {run, double_jump})` from `bot/index.ts` (stand, walk, run, and the double jump
  of the fastest); a local `createSim` flight is the fallback.
- `verifyRun(level, replay, claimed)` before submitting a run (`accepted`, `reason`), and on a challenger's replay for
  the banner's time and falls.
- `analyze(level, {mode})` for `#/dev` (full) and the library dry run (fast).
- **Not done:** the live "0.4 s to go!" split during a race (`ghostTrack(...).splitClock`) needs per-frame player
  state from the engine, which `GameHandle` does not expose; the result line uses the win payload's ghost results.

## Lane E
- Ghosts carry `kind` (`challenger`, `leader`, `pb`, `you`) and `sprite_url`; the win payload's `ghosts[].time_ms`
  feeds the "You beat Maya by …" line before the server verifies.
- Results card: `createMixer({muted})` with `whoosh`, `stamp`, `pb`, `beat`.
- Publish uploads `shareCardPNG(level, ink, {style: 'clean'})`; "Challenge a friend" shares
  `shareCardFile(level, ink, {run})` when `navigator.canShare({files})`.
- Rules screen theme boxes use `themeSwatch` and `auditionTheme`; Character Studio's mini-stage is `RigPreview`.
- `#/dev` showcase levels (`web/src/app/showcase.ts`) are compiled tiles + entities with the normative geometry
  (left/right spikes use x0..x1 as the vertical extent and y as the face x), so they render without ink.

**Lanes:** B, A, E.
